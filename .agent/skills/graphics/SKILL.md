# 3Dグラフィックススキル

## 3Dライブラリ
- 3D描画はVulkanを使用
- 行列ライブラリはglmを使用

## 座標系
- 右手座標系
- X軸正方向が右方向
- Y軸正方向が上方向
- Z軸正方向が手前方向
- 行列は列優先

## カメラ
- マウスホイールでズーム
- マウス左クリックのドラッグで回転
- マウス中ボタンのドラッグでカメラの並行移動
- マウス右クリックはメニュー用なのでカメラの操作は行わない
- 平行投影と透視投影を切り替え可能
