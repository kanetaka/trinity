# プロジェクトルール（trinity）

## プロジェクトの目的
- 高速な計測・通信・描画処理を組み合わせた手軽に使える3Dスタジオの開発

## 開発環境
- Windows/Linux/MacOSのクロスプラットフォーム対応
- 開発言語はC/C++
- 3D APIはVulkan
- ビルドシステムはCMake

## アーキテクチャ
- ECSアーキテクチャを採用し、同じ型のメモリを連続させるようにする
- 変換マトリックスは連続したメモリ領域に配置し、GPUで一括処理できるようにする

# ファイル構成
- assets : 3Dモデルやテクスチャなどのアセットを格納する
- assets/models : 3Dモデルを格納する
- assets/textures : テクスチャを格納する
- assets/shaders : シェーダープログラムを格納する
- build : ビルド成果物を格納する。コミットしない
- docs : ドキュメントを格納する
- docs/specs : 仕様書を格納する
- src : ソースコードを格納する
- src/core : コアライブラリのコードを格納する。Entity, Component, System, Registryなど
- src/core/ecs : ECSアーキテクチャのコードを格納する
- src/core/math : 数学ライブラリのコードを格納する
- src/stream : 入出力ライブラリのコードを格納する
- src/render : レンダリングのコードを格納する
- src/render/components : 具象コンポーネントのコードを格納する
- src/ui : UIのコードを格納する
- src/app : アプリケーションのコードを格納する
- tools : ツールプログラムのコードを格納する

## コード規約
- 文字コードはBOMなしUTF-8にする
- 改行コードはLFで統一する
- gitのcore.autocrlfはfalseにする
- インデントはスペース4つ
- インデントにタブは使用しない
- 行末の不要な空白は削除する
- クラス、構造体、関数、列挙体の最初の{（波カッコ）は次の行に配置する。1行で書ける場合は1行で書く
- if文、else文、for文、while文、do-while文、switch文の最初の{（波カッコ）は次の行に配置する。1行で書ける場合は1行で書く
- if文、else文、for文、while文、do-while文、switch文と(（丸カッコ）の間にはスペースを1つ入れる
- ポインタの*は型名にくっつける
- 参照の&は型名にくっつける
- コメントは英語で書く

## 命名規則
- ファイル名はローワースネークケース
- クラス名はアッパーキャメルケース
- 構造体名はアッパーキャメルケース
- プライベートメンバ変数はローワースネークケースで、末尾に_をつける
- プロテクテッドメンバ変数はローワースネークケースで、末尾に_をつける
- パブリックメンバ変数はアッパーキャメルケース
- グローバル変数はローワースネークケースで、末尾に__をつける
- ローカル変数名はローワースネークケース
- 定数はアッパースネークケース
- 関数名はアッパーキャメース
- 列挙体はアッパーキャメルケース
- 略語でもアッパーキャメルケースにする（例:Ubo, Gpu, Jpegなど）

## 禁止事項
- 勝手なコード整形成やリファクタリングを行わない
- ユーザーの明示的な指示がない限り、コードのスタイル（インデントや改行など）を変更しない
- メンバ変数の先頭にm_はつけない
- グローバル変数の利用は禁止
- 重複するコード禁止
