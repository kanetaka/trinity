# 3Dグラフィックススキル

## 3Dライブラリ
- 3D描画はVulkanを使用
- 行列ライブラリはglmを使用
- シェーダーはSlangで記述し、slangcでSPIR-Vにコンパイルする

## 座標系
- 右手座標系
- X軸正方向が右方向
- Y軸正方向が前方向
- Z軸正方向が上方向

## 行列とベクトル
- 行列は列優先
- ベクトルは列ベクトル

## カメラ
- カメラ相対レンダリング
  - 頂点シェーダーに渡す前に、CPU側で「オブジェクトの座標 - カメラの座標」を計算し、その結果（相対座標）をシェーダーに送る
- マウスホイールでズーム
- マウス左クリックのドラッグで回転
- マウス中ボタンのドラッグでカメラの並行移動
- マウス右クリックは使わない

## 投影方法
- 平行投影と透視投影を切り替え可能
